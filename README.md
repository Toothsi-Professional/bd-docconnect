# BD DocConnect

The iPhone / iPad web app for BD DocConnect (toothsi field BD teams).

- `home/` – field app for BDMs · `admin/` – admin console
- All data, sign-in and logic live in the BD DocConnect Google Apps Script project; this site is only the front page. It loads the latest pages from Apps Script, so updates there appear here automatically.
- Android phones are asked to use the official Android app.
- Settings: `assets/config.js` (API address).
